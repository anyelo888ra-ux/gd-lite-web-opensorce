# 🎮 Geometry Dash Lite - Web Edition (Open Source)

¡Una experiencia interactiva para jugar **Geometry Dash Lite** directamente en el navegador web a través de emulación en la nube!

> ⚠️ **DESCARGO DE RESPONSABILIDAD Y SEGURIDAD IMPORTANTE:**  
> Este entorno está diseñado exclusivamente para jugar la versión demo/lite pública. **NUNCA introduzcas datos personales, cuentas de Google, ni contraseñas** en el emulador. Es una sesión pública y cualquier información podría ser visible para otros usuarios.

---

## 🚀 Características

* ⚡ **Sin instalaciones:** Juega directamente desde el navegador web.
* 🔒 **Modo Kiosko:** Carga automática de Geometry Dash Lite sin acceso al sistema Android.
* 🌐 **Transmisión de baja latencia:** Control directo desde la interfaz.
* 🧹 **Sesiones efímeras:** Se recomienda limpiar datos al desconectarse.

---

## 🛠️ Estructura del Proyecto

* `public/index.html`: Interfaz web con aviso de seguridad modal.
* `public/styles.css`: Estilos visuales adaptados a temas oscuros.
* `public/app.js`: Lógica para gestionar la transmisión e interacción.
* `docker-compose.yml`: Configuración de entorno y servicios.
